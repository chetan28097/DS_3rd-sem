# Lab 9 - Heart Disease Prediction with Machine Learning and PCA

- `Lab-9.ipynb` - complete solution: Z-score outlier removal, label / one-hot encoding, train-test split with leak-free scaling, KNN / Logistic Regression / Decision Tree / Random Forest, GridSearchCV with 5-fold cross-validation, PCA (95% variance -> 13 of 15 features) and a before-vs-after PCA comparison with written answers (Q1-Q9).
- `heart.csv` - Heart Failure Prediction dataset (918 records, from Kaggle).

Key result: KNN is the best model both before PCA (test accuracy 0.894) and after PCA (0.911).
