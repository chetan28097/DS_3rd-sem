# Data Science Lab - Semester 3

Each lab folder holds its notebooks and the data they read. Run a notebook from inside its own folder so relative paths like `income.csv` resolve.

| Lab | Topic | What it covers | Main notebooks | Data |

| [lab1](lab1) | Data collection | Collecting real-world data by web scraping and from weather / air-quality sources (Bengaluru, Delhi) | `1st assignment`, `delhi weather and aqi`, `exercise` | `bengaluru_*.csv`, `books_data.csv`, `quotes.csv` |

| [lab4](lab4) | Hypothesis testing | One- and two-tailed Z-test and t-test, plus an assignment | `Lab-4`, `Z_t_Test_Assignment` | built into the notebooks |
| [lab4b](lab4b) | Probability distributions | Bernoulli, Binomial, Poisson, Normal and Uniform distributions, plus an assignment | `Lab-4-b`, `Lab-4-b-Assignment` | generated in the notebooks |
| [lab5](lab5) | Linear regression | Single-input linear regression (height vs weight) and food-delivery-time regression with gradient descent | `Lab-5`, `Lab-5-Assignment` | `weight-height.csv`, `Food_Delivery_Times.csv` |
